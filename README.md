# Rohliky - nákupní seznam

Neoficiální aplikace k nakupování na Rohlik.cz postavená kolem nákupního seznamu.

- Ke každé položce lze přiřadit konkrétní produkty a přidat je do košíku
- zobrazení produktů v tabulce (pro mě přehlednější než mřížka s fotkami)
- kontrola košíku a platba probíhá na webu Rohlíku.

## Webová aplikace

Běží na Cloudflare Pages: **https://rohliky.pages.dev**
